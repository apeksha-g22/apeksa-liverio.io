## ✨ What is Liverio?

Liverio is a full-stack clinical intelligence application that predicts liver disease from 10 standard blood test biomarkers. Enter your lab values, and Liverio instantly delivers:

- 🧠 **ML Prediction** — Binary liver disease classification (Yes/No) with confidence scores
- 📊 **Risk Stratification** — Low / Medium / High risk categories
- 💡 **Personalised Recommendations** — Diet, lifestyle, and medical advice tailored to your biomarker profile
- 🔍 **Explainability** — SHAP-based feature importance ("Why this prediction?")
- 📄 **PDF Report** — Downloadable clinical report
- 🤖 **AI Chatbot** — Liver health Q&A (optional Claude API integration)
- 🎤 **Voice Input** — Speak your lab values (Chrome/Edge)

## 🚀 Quick Start

### Prerequisites

- Python 3.9 or higher
- pip
- (Optional) A modern web browser with Chrome/Edge for voice input

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/liverio.git
cd liverio
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the ML Model

```bash
python ml/train_model.py
```

This will:
- Load and clean the ILPD dataset (583 patients, 10 features)
- Handle 4 missing `Albumin_Globulin_Ratio` values with median imputation
- Apply SMOTE to balance the class imbalance (416 disease / 167 healthy)
- Train 4 models: Logistic Regression, Random Forest, Gradient Boosting, XGBoost
- Select the best by ROC-AUC and save artefacts to `backend/models/`

**Expected output:**
```
🏆 Best model: Logistic Regression (AUC=0.8186)
✅ All artefacts saved to: backend/models
```

### 4. Start the Backend API

```bash
cd backend
cp .env.example .env        # configure if needed
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

API available at: **http://localhost:8000**  
Interactive docs: **http://localhost:8000/docs**

### 5. Open the Frontend

```bash
# Option A – open directly in your browser
open frontend/index.html

# Option B – serve with Python
cd frontend && python3 -m http.server 3000
# Visit http://localhost:3000
```

> **Note:** The frontend works offline in demo mode. For ML-backed predictions, ensure the backend is running on port 8000.

## 📡 API Reference

### `GET /health`
Health check.
```json
{ "status": "ok", "model_loaded": true }
```

### `GET /model-info`
Model metadata and performance metrics.
```json
{
  "model_name": "Logistic Regression",
  "test_accuracy": 0.735,
  "test_roc_auc": 0.8186,
  "test_f1": 0.7891,
  "feature_importance": { "Alamine_Aminotransferase": 0.19, ... }
}
```

### `POST /predict`

**Request:**
```json
{
  "age": 45,
  "gender": "Male",
  "total_bilirubin": 1.2,
  "direct_bilirubin": 0.4,
  "alkaline_phosphotase": 200,
  "alamine_aminotransferase": 35,
  "aspartate_aminotransferase": 30,
  "total_proteins": 6.8,
  "albumin": 3.5,
  "albumin_globulin_ratio": 1.0
}
```

**Response:**
```json
{
  "prediction": 0,
  "prediction_label": "No Liver Disease",
  "probability": 0.2843,
  "risk_level": "Low",
  "health_score": 72,
  "feature_importances": { ... },
  "model_name": "Logistic Regression"
}
```

### `POST /recommendations`
Returns personalised diet, lifestyle, and medical recommendations.

### `POST /full-report`
Combined endpoint — prediction + recommendations + input summary in one call.

## 🧠 ML Pipeline

```
ILPD CSV (583 patients)
   │
   ├── Data Cleaning
   │     • Fill 4 missing Albumin_Globulin_Ratio with median
   │     • Encode Gender (Male=1, Female=0)
   │
   ├── Train / Test Split (80/20, stratified)
   │
   ├── SMOTE Oversampling
   │     • Balances 416 disease vs 167 healthy → 333 each
   │
   ├── StandardScaler (z-score)
   │
   ├── Model Training
   │     ├── Logistic Regression
   │     ├── Random Forest (200 trees)
   │     ├── Gradient Boosting
   │     └── XGBoost
   │
   ├── Model Selection (best ROC-AUC)
   │
   ├── SHAP Feature Importance
   │
   └── Artefacts Saved (joblib + JSON)
```

## 💡 Recommendation Engine Logic

| Condition | Trigger | Recommendations |
|---|---|---|
| `total_bilirubin > 1.2` | Bilirubin elevated | Liver-friendly diet, hydration, no alcohol |
| `ALT > 56` or `AST > 40` | Enzymes high | Avoid alcohol/NSAIDs, stress reduction |
| `albumin < 3.5` or `proteins < 6.3` | Low protein synthesis | High-protein diet, dietitian consult |
| `albumin_globulin_ratio < 1.0` | Low A/G ratio | Anti-inflammatory foods, follow-up |
| `risk_level = High` | High probability | Urgent hepatologist consultation |
| `risk_level = Medium` | Moderate probability | GP within 2 weeks |
| `risk_level = Low` | Low probability | Annual check-ups |

## 🔧 Configuration

Create `backend/.env` (copy from `.env.example`):

```env
HOST=0.0.0.0
PORT=8000
LOG_LEVEL=INFO
ALLOWED_ORIGINS=*
MODEL_DIR=./models
```
